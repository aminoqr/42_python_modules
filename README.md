# 42 Python Modules

A comprehensive Python learning curriculum covering fundamental to advanced topics through practical garden-themed and fantasy-themed exercises.

## Module Overview

### Python Module 00 - Fundamentals
Basic Python operations and string manipulation.
- **ex00**: Hello Garden - Basic print statements
- **ex01**: Plot Area - Area calculations
- **ex02**: Harvest Total - Sum calculations
- **ex03**: Plant Age - Age calculations
- **ex04**: Water Reminder - Time-based logic
- **ex05**: Count Harvest - Iterative and recursive counting
- **ex06**: Garden Summary - Data summarization
- **ex07**: Seed Inventory - Inventory management

### Python Module 01 - Functions & Data Structures
Functions, dictionaries, and basic data manipulation.
- **ex00**: Garden Intro - Function introduction
- **ex01**: Garden Data - Data handling
- **ex02**: Plant Growth - Growth calculations
- **ex03**: Plant Factory - Factory pattern introduction
- **ex04**: Garden Security - Security functions
- **ex05**: Plant Types - Type classification
- **ex06**: Garden Analytics - Analytics and reporting

### Python Module 02 - Exception Handling
Error handling, custom exceptions, and try-except blocks.
- **ex0**: First Exception - Basic exception handling
- **ex1**: Different Errors - Multiple error types
- **ex2**: Custom Errors - Creating custom exceptions
- **ex3**: Finally Block - Resource cleanup
- **ex4**: Raise Errors - Raising exceptions
- **ex5**: Garden Management - Error handling in practice

### Python Module 03 - Object-Oriented Programming
Classes, inheritance, and object design.
- **ex0**: Command Quest - Command pattern implementation
- **ex1**: Score Analytics - Analytics with OOP
- **ex2**: Coordinate System - Geometric classes
- **ex3**: Achievement Tracker - Tracking system
- **ex4**: Inventory System - Inventory management with OOP
- **ex5**: Data Stream - Stream processing
- **ex6**: Analytics Dashboard - Dashboard implementation

### Python Module 04 - File & Stream Management
File I/O, streams, and data persistence.
- **ex0**: Ancient Text - Text file operations
- **ex1**: Archive Creation - Archive/compression
- **ex2**: Stream Management - Stream processing
- **ex3**: Vault Security - Secure file operations
- **ex4**: Crisis Response - Emergency file handling

### Python Module 05 - Advanced Data Processing
Data pipeline and stream processing.
- **ex0**: Stream Processor - Stream processing implementation
- **ex1**: Data Stream - Real-time data handling
- **ex2**: Nexus Pipeline - Advanced pipeline design

### Python Module 06 - Imports & Modules
Module organization, imports, and package structure.
- **ft_circular_curse.py**: Circular import handling
- **ft_import_transmutation.py**: Import transformations
- **ft_pathway_debate.py**: Module pathway resolution

### Python Module 07 - Advanced OOP & Design Patterns

## Getting Started

```bash
# Navigate to a specific module
cd "Python Module 00"

# Run an exercise
python3 ex00/ft_hello_garden.py
```

## Learning Path

1. **Modules 00-01**: Core Python fundamentals
2. **Module 02**: Error handling and robustness
3. **Module 03**: Object-oriented design
4. **Module 04**: File and stream operations
5. **Module 05**: Advanced data processing
6. **Module 06**: Module organization
7. **Module 07**: Complex OOP and design patterns
8. **Module 09**: Concurrent and parallel programming
9. **Module 10**: Functional programming paradigms

## Project Structure

Each module contains numbered exercises (ex0, ex1, etc.) that progressively build on previous concepts. Exercises are organized thematically around garden cultivation, magical systems, and space exploration.
